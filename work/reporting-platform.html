Case Study

Self-Serve Reporting Platform

Company — Audible Magic Corporation · Los Gatos, CA Role — Full-Stack Engineer Dates — Jan 2019 – Mar 2023
Python AWS Lambda S3 Elastic Beanstalk CloudFormation

The problem

Clients kept coming back with one-off report requests. Each one ate engineering time, and none of it was reusable — a manual pattern standing in for a real solution.

What I did

  • Recognized the repeated requests as a solvable platform problem, not a series of one-offs.
  • Designed and shipped a self-serve reporting platform (Lambda + S3 + Elastic Beanstalk) that let clients generate their own reports on demand.
  • As part of the same architectural mandate, set the direction for migrating fragmented legacy services into a cohesive microservices platform on AWS.
  • Authored CloudFormation-based CI/CD automation and a shared C# middleware library that became org-wide defaults, reducing new-service setup time.
  • Designed a reusable scheduler service (Quartz.NET) and Redis caching layer that multiple teams adopted for their own pipeline needs.

Outcome

The manual request pattern was eliminated entirely, freeing up engineering time that had been going to one-off client reports.
