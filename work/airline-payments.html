Case Study

Airline Payments & Booking

Company — Alaska Airlines (via Fuel Talent, remote) Role — Senior Software Engineer Dates — May 2023 – Dec 2025
C# Node.js TypeScript Svelte React Azure Sabre

The problem

Same-Day Change and Ancillary Payments is a high-traffic e-commerce feature on Alaska Airlines' mobile app. It needed to support more payment methods reliably, and no one had yet made the case — or built the plan — for adding modern options like Apple Pay on top of the existing Sabre-based payment infrastructure.

What I did

  • Identified the need for Apple Pay as a first-class payment method, built the technical case, and aligned stakeholders across mobile, backend, and payments engineering.
  • Led end-to-end implementation integrating with Sabre's payment gateway — one of the core systems airline booking infrastructure runs on.
  • Independently scoped, designed, and shipped a multi-payment-option system spanning backend services and frontend booking flows, owning the product decision rather than just the implementation.
  • Drove cross-team alignment on shared integration standards and observability practices for new payment systems, establishing common ground before complexity compounded.
  • Designed and owned monitoring dashboards giving non-engineering stakeholders self-serve visibility into system health, performance, and user interaction metrics.
  • Established coding standards and mentored junior engineers through code review and architectural guidance.

Outcome

The multi-payment-option system is now used across booking flows, and the monitoring dashboards let stakeholders self-serve operational insight without pulling in engineering time for every question.
