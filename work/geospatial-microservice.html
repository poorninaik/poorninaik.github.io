Case Study

Geospatial Ordering Microservice

Company — CardFree · San Francisco, CA Role — Software Engineer Dates — Sep 2015 – Jun 2017
MongoDB Geospatial AWS .NET C#

The problem

CardFree's mobile commerce platform ran on on-prem infrastructure with a scalability ceiling, and the product needed location-aware ordering — knowing which store a customer was near, reliably enough to route their order correctly.

What I did

  • Identified the scalability ceiling in the on-prem setup and made the technical case for migrating to AWS (EC2, S3, CloudFront, ElastiCache).
  • Designed a proximity microservice using MongoDB's geospatial features to power location-aware ordering.
  • Owned the integration architecture for third-party services — Google Pay, OAuth, MapQuest, and Omniware — working directly with product to shape requirements rather than waiting for a spec.

Outcome

The AWS migration improved reliability and cut image load times. The proximity microservice became the foundation for the location features that followed it.
