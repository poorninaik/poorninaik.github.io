Side Project

TipCalc — iOS Tip Calculator

Type — Personal project Platform — iOS / Xcode Language — Swift
Swift iOS Xcode Unit Testing UI Testing
View on GitHub →

What it is

A small native iOS app: enter a bill amount, choose from a few preset tip percentages, and see the calculated tip and total update instantly. Nothing complicated by design — it's a focused, well-tested app rather than a sprawling one.

Why I built it

My day-to-day work is backend- and web-heavy. TipCalc was a hands-on introduction to iOS development in Swift and Xcode outside that comfort zone — a way to actually write and ship native mobile code rather than just read about it.

Details

  • Built in Swift using Xcode, with a standard iOS project structure.
  • Includes both unit tests and UI tests alongside the app code.
  • Simple, deliberately scoped: bill entry, tip-percentage selection, live calculated total.
